# Страница «Книга директора» — передача в разработку

## Что в папке

| Файл | Что это |
| --- | --- |
| `book-page.html` | Готовый макет страницы. Открывается в браузере как есть. Адаптивный: десктоп, планшет (≤1100 px), телефон (≤640 px). |
| `tokens.css` | Цвета, отступы, скругления и шрифт бренда в виде CSS-переменных. |
| `hero-loader.jpg` | Фото для фона шапки страницы. |
| `kniga-direktora.pdf` | Файл книги для кнопки «Скачать PDF». |

## Задача для Claude Code

Скопируйте эту папку в проект сайта и напишите Claude Code:

> Внедри страницу «Книга директора» по макету из папки `kniga-direktora/`. `book-page.html` — эталон дизайна, `tokens.css` — цвета и отступы бренда, `HANDOFF.md` — требования. Используй существующие шапку, футер и стили сайта, а не копии из макета. Сохрани адаптивность (1100 px и 640 px). Все кнопки «Скачать» должны вести на `kniga-direktora.pdf`. После внедрения сверь результат с макетом на ширине 1280 и 390 px.

## Требования

- **Шапка и футер в макете — заглушки.** Используйте компоненты, которые уже есть на сайте. В меню активен пункт «Руководителям проектов».
- **Структура страницы:**
  1. Шапка страницы: «Книга директора», название исследования, авторы, кнопка «Скачать PDF · 1,2 МБ» и якорь «Кратко о книге» (`#walk`).
  2. Полоса из четырёх цифр.
  3. Секция `#walk` «Три главы за три минуты»: цитата из введения и три главы.
  4. Тёмный блок «Выводы и предложения — в полной версии» с кнопкой скачивания.
- **Телефон:** меню свёрнуто в бургер, обложка стоит над заголовком, цифры идут сеткой 2×2. Внизу экрана закреплена плашка `.dock` с кнопкой «Скачать» (`position: sticky`, учитывает `safe-area-inset-bottom`).
- **Ссылки на скачивание:** у всех кнопок «Скачать» нужно поставить `href` на PDF и атрибут `download`. Размер и число страниц: 1,2 МБ, 74 страницы.
- **Шрифт:** Montserrat (Google Fonts, 400–800). Его определили по скриншоту на глаз. Если на сайте другой шрифт, используйте его.
- **Кнопки:** золотая кнопка `--gold-500` с тёмным текстом `--ink-900`. Белый текст на золоте не проходит по контрасту.
- **EN-версия:** тексты на английском пока не готовы. Страницу нужно сделать с учётом переключателя RU/EN.
- **Не хватает данных:** фото авторов и справки о Т. С. Ергалиеве. В текущем макете они не используются.

Весь текст на странице взят из PDF: «Оценка государственной политики в отрасли железнодорожного транспорта в Казахстане», Б. Р. Кадиров, Т. С. Ергалиев, Астана, 2025.
